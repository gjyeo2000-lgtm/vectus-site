# Vectus 홈페이지 보험 안내·탐색 보강 설계 및 구현명세

## 목적과 현황

- 대상은 `vectuslab.com` 회사 홈페이지의 한국어·영어 정적 페이지다. 보험 진단 엔진이나 운영 DB는 변경하지 않는다.
- 2026-10-14 Playwright 실측: 보험 문구와 그래프는 양 언어에서 표시된다. 그러나 모바일에서 보험·문의 메뉴가 숨겨지고 대체 메뉴가 없다. 공개 헤더의 웹 링크는 비밀번호가 필요한 `test.vectuslab.ai`로 이동한다. 영어 320px에서 19px 가로 넘침이 있다. `prefers-reduced-motion: reduce`에서도 보험 연결선이 4.5초 무한 반복한다.
- 메시지는 중요한 특약·청구 조건을 공식 약관 근거로 확인하고, 이해하기 쉽게 설명하며, 반복 대조 시간을 줄이는 **목표**를 한눈에 전달해야 한다. 누락 제로·지급 보장·설계사 대비 속도 우위는 주장하지 않는다.

## 화면 설계

1. 데스크톱 헤더의 외부 링크는 `테스트 웹 · 초대자 전용` / `Test Web · Invite Only`로 표시한다. 목적지와 새 탭 동작은 유지한다.
2. 980px 이하 헤더에는 로고와 KO/EN 링크를 유지하면서 키보드로 조작 가능한 `메뉴` / `Menu` 토글을 둔다. 768px 영어 헤더에서 긴 링크가 두 줄로 접히는 현상도 이 기준으로 방지한다. 펼침 패널은 기존 여섯 구역 링크와 초대자 전용 테스트 웹을 포함한다. 구역 링크 클릭과 Escape 키로 닫고, Escape 시 포커스는 메뉴 토글로 돌아간다. 넓은 데스크톱 메뉴는 그대로 유지한다.
3. 보험 소개 첫 문단 아래에 한 문장 가치 제안을 둔다: 공식 약관의 중요한 특약·청구 조건 확인 → 쉬운 설명 → 반복 진단 시간 축소. 기존 고객 우선·준비 중·실제 지급 조건 문구는 유지한다.
4. 영어 320px의 넘침은 히어로 그리드 자식의 최소 너비와 긴 제목 단어의 실제 너비를 해소한다. 360px 이하에서만 제목 크기를 조정하며 본문을 잘라 숨기거나 전체 `overflow-x:hidden`에만 의존하지 않는다.
5. `prefers-reduced-motion: reduce`일 때 보험 연결선 및 반복 장식 애니메이션과 자동 부드러운 스크롤을 정지하고, 의미 있는 최종 상태는 계속 보인다. 일반 모션은 보존한다. 구역 앵커에는 고정 헤더 높이만큼 스크롤 여백을 둔다.

## 단계별 작업

1. `origin/main` 기준 별도 브랜치·워크트리를 만들고 이 설계·명세를 기록한다.
2. 양 언어 HTML의 헤더·보험 가치 제안과 공통 모바일 메뉴 CSS/JS를 구현한다.
3. 영어 히어로 좁은 화면 처리와 공통 reduced-motion CSS를 구현한다.
4. 정적 계약 테스트 및 Playwright로 320/390/768/1440px, KO/EN, 메뉴 클릭·Escape·앵커 이동·가로 넘침·모션 설정·목적지·콘솔 오류를 검증한다.
5. 커밋·push·ready PR·merge 후 `main` pull, GitHub Pages 배포와 실제 사이트를 확인하고 브랜치·워크트리를 정리한다.

## 파일·동작 계약

| 파일 | 변경 계약 |

| `index.html`, `en/index.html` | 동일한 모바일 메뉴 구조·번역, 초대 전용 링크의 명확한 라벨, 보험 가치 제안. 메뉴는 `details/summary`의 기본 접근성을 사용한다. |

| `tests/trust_copy.cjs` | 양 언어 문구·메뉴 항목·전용 링크·공통 CSS/JS 연결을 회귀 검증한다. |

## 수용 기준

- 모바일에서 `보험`/`Insurance`와 `문의`/`Contact`를 메뉴로 열어 이동할 수 있다. 토글은 키보드 접근 가능하고 Escape로 닫힌다.
- 공개 헤더 어디에도 테스트 서비스를 정식 공개 웹처럼 부르는 링크가 없다. 목적지는 여전히 테스트 환경이며 권한 경계는 바뀌지 않는다.
- 보험 가치 문구가 네 요소(공식 근거, 중요 특약·청구 조건, 쉬운 설명, 반복 시간 축소)를 담되 결과·속도를 보장하지 않는다.
- 두 언어에서 320/390/768/1440px 가로 넘침, 깨진 이미지·앵커, 페이지 오류가 없다.
- reduced motion에서는 보험 연결선이 움직이지 않고 일반 설정에서는 움직인다.
