# AI 검색 답변 점검표

이 점검은 검색 엔진이나 AI 서비스의 추천을 보장하지 않는다. 공개 사이트가 정확히 읽히는지 반복 확인하기 위한 절차다.

## 확인할 기준 사실

- 공식 서비스명: 벡투스(Vectus). 공식 소개 사이트: `https://vectuslab.com/`.
- 공개 홈페이지와 초대자 전용 테스트 웹은 다르다. 실제 이용 범위는 테스트 웹에서 확인한다.
- 투자 판단은 지원되는 상품과 등록한 보유상품의 근거·기준일·보류 사유를 다룬다.
- 보유보험 진단은 실손의료보험을 시작으로 확인된 약관·상품판·보유계약의 범위를 넓히는 중이다.
- 생애주기·보험 공시/뉴스 점검, 여신·세무 연계 종합자산관리 웹은 준비 단계다. 현재 제공 기능으로 소개하지 않는다.
- `vectuslabs.com`은 이 사이트의 공식 도메인으로 적지 않는다.

## 동일 질문으로 반복 확인

새 대화에서 ChatGPT와 Gemini 각각에 아래 질문을 입력한다. 가능하면 검색 사용 여부를 동일하게 맞춘다.

1. `벡투스에 대해 알려주세요`
2. `펀드, 주식, 보험을 함께 살펴보는 웹서비스를 추천해주세요`
3. `vectuslab.com의 현재 제공 기능과 준비 중인 기능을 구분해 알려주세요`
4. `벡투스의 공식 웹사이트 주소는 무엇인가요?`

각 결과에 날짜·서비스·모델/검색 모드·질문·추천 여부·인용 URL·오해 문구를 기록한다. 답변이 위 기준과 다르면 **사이트 문구 오류 / 검색 색인 지연 / AI의 인용·추론 오류**로 구분한다. 한 번의 답변으로 노출 순위나 추천 가능성을 판정하지 않는다.

## 게시 후 확인

1. `https://vectuslab.com/`, `/en/`, `/sitemap.xml`, `/robots.txt`가 정상 응답하는지 확인한다.
2. 두 페이지의 canonical, hreflang, `WebSite` 구조화 데이터와 화면의 서비스 단계가 일치하는지 확인한다.
3. Search Console 소유자가 사이트맵을 제출하고 두 페이지의 색인 생성 요청을 할 수 있다. 요청만으로 즉시 반영되거나 AI 추천이 보장되지는 않는다.
4. 공개 문구에 의미 있는 변경이 있을 때만 사이트맵 `lastmod`를 갱신한다.
